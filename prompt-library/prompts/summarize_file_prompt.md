# File Content Summarizer

Provide a concise summary of non-delimited file content.

## Input
- File path: {file_path}

## Summary Requirements
- Identify file type and purpose
- Extract key information
- Highlight main topics or sections
- Note file structure and organization

## Output Format
```
File Summary: [filename]

Type: [file type]
Size: [approximate size/length]

Key Content:
- [Main point 1]
- [Main point 2]
- [Main point 3]

Structure: [Brief description of how content is organized]
```

## Instructions
- Keep summary concise but informative
- Focus on actionable insights
- Identify programming language if code file
- Note any special formatting or patterns

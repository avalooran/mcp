# Project Template

Base project structure located at: `templates/project_template/`

**Structure:**
- Spring Boot 3.1.5 with Java 17
- Maven build system
- Standard Spring Boot directory layout
- Pre-configured application.properties
- Sample controller, service, and DTO classes
- Integration examples for all framework modules

**Essential Files:**
- pom.xml, application.properties, Spring Boot main class, one service, one controller
- Ensure project compiles with selected modules and Spring Boot only

**Usage:**
Copy this template as the foundation for new custom framework projects.
